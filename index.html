Keyboard shortcuts

  • Practice: ↑ ↓ choose option · Enter select (or next question once answered) · 1-4 / A-D pick option · ← → previous / next question · H hint · S show answer · J justification · R reset · M switch to Test
  • Test: ↑ ↓ move through options · Enter / Space select · 1-4 / A-D pick option and jump to next question · ← → previous / next question · Shift+Enter Save Answers · M switch to Practice
  • Study: ↓ → next question · ↑ ← previous question · Home / End first / last · / focus search
  • Any tab: Ctrl+← → or [ ] change tab
